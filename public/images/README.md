# Images

- `profile.jpg` — your photo. Add it here, then set `photo: "/images/profile.jpg"` in `src/content/profile.ts`.
- `projects/*.jpg` — project screenshots. Add them here, then set `image: "/images/projects/your-file.jpg"` on the matching entry in `src/content/projects.ts`.

Until these are added, the site shows designed placeholders instead of broken images.
